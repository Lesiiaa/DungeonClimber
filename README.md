## Project Overview :rocket:
Dungeon Climber was created as a final project for the **"Programming in Unity"** course.  
It is a **single-player, dungeon crawler game** inspired by *The Binding of Isaac*. The game is **2D**, with a **top-down perspective** and a camera that follows the player. It was developed in **C# using the Unity Engine**.

The game was created by a team of 4 people.

---

## Features :fire:
- Exploration
- Combat
- Keys and bombs mechanics for opening passages  
- Storytelling through collectible notes  
- Collectible items

---

- Unity Engine 6000.0.41f1 LTS
- C#
- Assets from Unity Asset Store, itch.io, Pixabay, as well as custom-made graphics created by our team members
